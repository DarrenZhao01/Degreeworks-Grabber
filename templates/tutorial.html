How to Use the Course Finder

Step 1: Enter Your Course String

In the main input box labeled "Enter DegreeWorks String", paste or type the course information directly from DegreeWorks. The application is designed to understand strings like "1 Class in ANTHRO 2A, 20A, ARABIC 2A, 2B" or simpler forms like "COMPSCI 111, 121, I&C SCI 31".

Note: Processing time is dependent on the number of courses you have. For example, processing 10 courses takes around 30 seconds, and processing 20 courses takes around 1 minute.

The parser can handle:

  • Courses from different departments in one string.
  • Multi-word department names (e.g., I&C SCI).
  • Various spacing and formatting inconsistencies.
  • Common prefixes like "X Class(es) in" will be automatically ignored.

Step 2: Select Year and Quarter

Use the dropdown menus to select the academic Year (e.g., 2024) and the specific Quarter (e.g., Fall, Winter, Spring, Summer1, etc.) for which you want to find course sections.

Step 3: Submit Your Query

Click the "Find Sections" button. The application will then start processing your request.

Step 4: View Results

As the application fetches data, you'll see real-time updates:

  • A progress bar will show the overall search progress.
  • Log messages will indicate which course is currently being searched or if any errors occur for a specific course.
  • Once complete, the results will be displayed below. For each course, you'll see:
    • The course name (e.g., ANTHRO 2A).
    • Sections grouped by type (Lecture, Discussion, Lab, etc.).
    • For each section: section code, type, instructor(s), status (e.g., OPEN, FULL), meeting times and locations, and units.
    • If an error occurred while fetching data for a specific course (e.g., API timeout, course not found for the selected term), an error message will be shown for that course.

If no sections are found for a course in the selected term, it will be indicated.

Troubleshooting Common Issues

  • "Invalid input provided" / "Missing required fields": Ensure you have filled in the course string, selected a year, and chosen a quarter.
  • "Invalid year format": Make sure the year is a 4-digit number (e.g., 2024).
  • "Error parsing the course string" / "No valid courses could be parsed":
    • Check your input string for typos.
    • Ensure course numbers are present after department names. For example, COMPSCI alone is not enough; it needs a number like COMPSCI 111.
    • The system tries its best with complex strings, but extremely unusual formatting might cause issues. Try simplifying the string if problems persist.
  • API Errors (e.g., "timed out", "returned no data", "HTTP error"): These errors usually mean there was a problem contacting the external course API. This could be due to a temporary issue with the API itself, network problems, or the requested course data not being available. Try again later. If the issue persists for many courses, the API service might be down.
