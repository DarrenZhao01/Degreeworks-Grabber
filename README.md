# DegreeWorks Course Finder

A web application that helps you find available course sections based on your DegreeWorks string.

## Features

- Paste your DegreeWorks string
- Select your desired term and year
- View course sections in a clean, organized table
- Progress indicator while processing
- Responsive design for all devices

## Installation

1. Install the required dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```

3. Open your web browser and navigate to `http://localhost:5000`

## Usage

1. Paste your DegreeWorks string in the text area
2. Select your desired year
3. Choose the quarter
4. Click "Find Courses"
5. View the results in the organized table below

## Requirements

- Python 3.7+
- Flask
- Requests
- Bootstrap 5
- Font Awesome
